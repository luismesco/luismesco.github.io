# Coordinaciones estatales 2027

Mapa interactivo y fichas documentadas de las coordinaciones estatales de la Defensa de la Transformación y la Soberanía Nacional anunciadas al 16 de septiembre de 2026.

La información de cada perfil incluye enlaces directos a las fuentes consultadas y una ficha JPG descargable para WhatsApp.
